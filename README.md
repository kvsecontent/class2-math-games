# Class 2 Maths – Smartboard Games (Joyful Mathematics)

Interactive games for a 75" smartboard. Open `index.html` → pick a chapter tab → tap a game.

- `index.html` – dashboard with chapter tabs (add new chapters to the `CHAPTERS` list)
- `assets/` – shared style and helpers (`common.js`: quiz, drag/tap, speech, sounds; `math.js`: number pad, ten strips, number words; `tug.js` + `tug.css`: two-player Tug of War)
- `ch1/` – Chapter 1 "A Day at the Beach" (21 games)
- `ch2/` – Chapter 2 "Shapes Around Us" (10 games; `assets/instruments.js` has the instrument drawings)
